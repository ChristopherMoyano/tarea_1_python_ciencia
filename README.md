# tarea_1_python_ciencia
 
Repositorio para la tarea 1 de Taller de Python para ciencia de datos.

## Requerimientos para ejecutar el codigo
- Python 3
- Jupyter notebook
o
- Cuenta de Google para Google Colab (si se desea ejecutar en este entorno)

## Como ejecutar el codigo

### En Visual Studio Code
1. Descargar el archivo comprimido.
2. Extraer su contenido en una misma ubicación.
3. Abrir Visual Studio Code.
4. Abrir el archivo "Tarea_1.ipynb".
5. Ejecutar las celdas en orden.

### En Google Colab
1. Descargar el archivo comprimido.
2. Extraer su contenido en una misma ubicación.
3. Ir a: https://colab.research.google.com/ e iniciar sesion.
4. Subir el contenido del archivo comprimido a la sesion de Colab.
5. Abrir el archivo "Tarea_1.ipynb".
6. Ejecutar las celdas en orden.

## Archivos o directorios importantes
- "Tarea_1.ipynb" que contiene el codigo de la tarea
- "Libros_txt_utf-8/" que contiene los libros de prueba para la tarea
